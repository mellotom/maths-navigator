# maths-navigator

travelers guide for counting to infinity: a one-page reference for the **make noise maths** (2013 revision). rise, fall and vari-response, cycle, eor and eoc, channels 2 and 3 offsets, the sum / or / inv bus, timing, and the patches from the manual, with diagrams.

source: the make noise maths manual (2013).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with make noise.
